# 寄一个世界给你 · Postcard World

**Tripothon S1（首届世界构建黑客松）交互作品** —— 在线试玩：<https://pawer1108.github.io/postcard-world/>

它不是`一个`世界，而是**一台送世界的机器**：你把一个真实的人写进去，
它生成一个只属于那个人的微缩世界，你拿到一条链接，把链接发给他。

## 玩什么

| 打开 | 看到 |
|---|---|
| 首页 | **创作者模式**：填"送给谁"和一句话，选天色，点地面摆物件，拿到专属链接 |
| [#w=demo](pawer1108.github.io/postcard-world/#w=demo) | **收件人模式**：走进一个别人送的世界，走到中心，那句话会浮出来 |

## 设计要点

- **零后端**：名字、那句话、天色、物件坐标全部 base64url 编码进 URL hash。
  满配世界 161 字符。没有服务器、没有数据库、没有登录。
- **世界只有 6.5 米半径**：礼物不需要很大，它只够装一件事、一个人。
- **音景全程序化合成**：雨、风、脚步、轻响都用 WebAudio 现场生成，零音频文件。
- **3D 资产由 [Tripo](https://www.tripo3d.com/) API 生成**（text_to_model，v3.1-20260211），
  贴图离线优化至 512²（法线保留 PNG），8 件从 20.43 MB 压到 4.42 MB。

## 本地运行

本仓库就是构建产物，不需要安装任何依赖：

```bash
node serve.mjs 8138
# 浏览器打开 http://127.0.0.1:8138/
```

也可以直接用任意静态服务器托管本目录。

## 技术

three.js r180（vendor 内置，零构建）· 原生 ES 模块 + importmap · 无打包器 · 无后端
